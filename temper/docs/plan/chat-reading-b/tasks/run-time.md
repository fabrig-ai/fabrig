# A run of one turn has a time

## Goal

A committed turn says only when it ended, so today a run of one turn, most of them, has no time. A run now measures from the line before its first turn, which says when that turn began.

Acceptance, in `temper-client-view/src/tests/chat_line.rs`, through `conversation`:

- **One turn:** a turn at 41 s after a turn at 12 s, holding one call, says "29 s".
- **After words:** a run whose line before it is the person's words measures from them.
- **A line the chat hides counts:** a run after `Activity::RunBegan`, an hour after the last turn, measures from that beginning, so hours waiting aren't counted. The hidden line still doesn't end a run.
- **Across turns:** three turns at 10, 20 and 30 s after a line at 5 s say "25 s".
- **The window's head:** a run of one turn with no line before it has no time, and a run of two turns at its head measures from its first turn's end.
- **A turn's second run:** in `[call, text, call]` the first run measures from the line before the turn, and the second from the turn's end, so it has no time.
- **Unchanged:** under a second has no time; a running run has none; the time past a minute is "N min".
- **The status:** the **Not yet** line "3.5, *its calls*, its description" is gone from `temper/docs/design/client/README.status.md`.
