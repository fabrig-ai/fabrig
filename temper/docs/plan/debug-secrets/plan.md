## What was decided

- **Two private records join the request's list, as the same bytes in the same crate:** `RequestLine` (a server's `Call` target while it is read) and `ReadState::Body` (an `Event::Body` while it fills). Without them, formatting the machine would print what the named record hides.
- **The status names more carriers than the request listed,** each untouched: lib's `stream::Down`, `stream::Up`, `Intake` and `Writer`; skein-channel's refusal text and `FrameWriter`; skein-http's `sse::Dispatch`.
- **`Refusal::Back`'s `location` stays,** as an open question in `oauth-issuer.md`, 10. It holds the client's state, but the request names only `Authorization`.
- **`EnvNames` is a private third copy in smith,** since skein-io's and skein-sim's are private, and a public helper in skein-io is more than "no reshaping" allows.
- **Debug-only tasks run their own package and world,** not their direct dependents: nothing outside reads the printed forms but the one test `channel-frames` changes (`notes/common.md`).
