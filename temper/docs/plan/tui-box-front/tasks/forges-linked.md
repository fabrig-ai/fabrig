# The forges document carries `linked`, false for now

## Goal

The interface step of "✓ Signed in as the owner": temper's `Forges` record,
the document of the `forges` watch every client opens at start, gains
`linked: bool`, whether the printed link has signed a person in since the
engine started (`temper/docs/design/client/README.md`, 4.6). This task adds
the field and fills it `false` everywhere; task `serve-sign-in` makes the
engine set it, and task `domain-front` makes the client read it.

Acceptance, by `notes/contracts.md`, section 3, *The wire*:

1. `schema/client-wire-v1.schema`: `versioned record Forges { forges: list
   16 ForgeRow linked: bool }`; `src/generated/v1.rs` and the goldens
   `golden/record_forges_full.bin` and `record_forges_smallest.bin`
   regenerated by their tool, never by hand:
   `SKEIN_CODEGEN_WRITE=1 heavy cargo nextest run -p temper-codecs-world --test suite -E 'test(drift::)'`,
   then the same without the variable, green. Any other golden the run
   rewrites is a red, not stale: stop and report it.
2. Every `ForgesParts { .. }` literal gains `linked: false`, the field
   alone (compiler-forced): `temper-service/src/family.rs:1060` (the
   engine's encoding, `false` until `serve-sign-in`), and the tests and
   tools that build the record (about 53 sites; `rg 'ForgesParts' temper`
   lists them: `temper-client-protocol-wire/src/tests.rs`,
   `temper-client-domain/src/tests/**`, `temper-client-view/src/tests/**`,
   `temper-client-tools/src/tests/**`, `temper-client-shell-*`'s tests and
   fixtures, `temper/tests/client/src/front.rs`,
   `temper/tests/codecs/tests/suite/{client_wire.rs,fuzzy/client_wire.rs}`,
   `temper/tools/gallery/src/{samples.rs,worlds.rs,worlds/github.rs}`).
   The client's decoding ignores the field: nothing reads it yet.
3. **One round-trip row:** in `temper-client-protocol-wire/src/tests.rs`,
   where the forges record is encoded and decoded (about lines 307-374,
   `forges_rows` and its test), a record with `linked: true` decodes back
   with `linked() == true` (or the generated accessor's name), and one with
   `false` as false.
4. `temper/docs/design/client/README.status.md`: delete the **Not yet**
   bullet naming `forges-linked`. No other design text changes.
