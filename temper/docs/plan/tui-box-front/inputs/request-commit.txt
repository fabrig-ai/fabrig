Look request (temporary): temper box with the TUI in front

Hand-made frames (client/tui/journeys/box-front/README.md) of
`temper box` run in a terminal with the TUI in front of it, as the user
settled it on 2026-11-08: the TUI is a small front end for the box.

- 01: a brand-new box: the welcome, from the first moment. The box
  hands out its sign-in link before temper is up and holds the TUI's
  connection until it is, as it does the browser's, so there's no
  starting screen. "Welcome. Set temper up in your browser: open this
  link on this machine.", the link printed whole (never opened by the
  TUI), what it does, and the browser's welcome steps, none started.
- 02: the link opened. The TUI follows the browser's welcome steps,
  read-only (signed in, then Welcome, Forge, Model, Ready). Setup never
  runs in the TUI: the forge is chosen and set up in the browser (a
  Forgejo fetched, GitHub connected, or the playground).
- 03: the playground chosen. The TUI works with it as with any project,
  and says it's the playground: "playground" in the header and on the
  quiet line, and the browser banner's words in the header's box, "This
  is the playground: a scripted model and in-memory forge. Set temper up
  in your browser when you're ready to leave it."
- 04: Ctrl+C while work runs: "Stop the box? ... stops with it." as a
  list under the box, "Stop the box" or "Don't quit". With nothing
  running, quitting stops the box at once.
- 05: a step of the box failing: "forge restarting" on the quiet line,
  and /log noting the box's recent log lines.

Also, from the user:
- `temper box --no-tui` runs the box as today, with no TUI. Where stdin
  or stdout isn't a terminal, the box runs as today too.
- The TUI started by the box signs in with nothing to read or paste,
  its secret handed out at once, as the browser's link is.
- In box mode, the place reads "box" at the default port and
  "box:PORT" at another, as tui-chat-title-below says.
- A box over SSH is the person's business (a tunnel); no UX for it now.

States the frames don't show: a step failing for good (the box gives up,
naming the step, and the TUI says so and stays open for /log); the light
theme.

Replaces: the box's printed block in a terminal (it goes to the box's
logs, the link to the TUI's welcome), and a second terminal for
`temper`.

Not the look's: almost all of it. The box starting the TUI and handing it
a sign-in, the TUI reading the box's steps and log, following the
welcome's steps, and quitting stopping the box are features
(temper/tui's, with the box). The sign-in builds on the link file
having its own secret, already asked.
