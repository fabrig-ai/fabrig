# look-round-22: what every task follows

- **The request binds:** `temper/docs/plan/look-round-22/inputs/request.md`, all of it, *For every task of this plan* first. It wins over a spec where they differ.
- **The look request** is a commit on `origin/look-requests`, found by its trailer, since the branch moves: `git log origin/look-requests --grep='Look-request: outside-pages'`; when cut, `43a18a5042`. Read it with `git show` alone, its whole message first, and its pages from its own commit (`git show COMMIT:PATH`, under `temper/docs/design/client/journeys/outside-pages/` and the overlay `temper/docs/design/client/journeys/overlay.css`), never from the branch's tip. Leave `origin/look-requests` itself alone. It landed in `look-outside-pages`; this plan repairs what the render check after it found (`temper/docs/design/draft/look-requests.md`, 3, 4 and 5).
- **The design this plan follows,** written by this cut, is cited by each spec's *Inputs*. Each task deletes the **Not yet** entry naming it and `look-round-22` in the status file its spec names, and edits no other design text: that departs from the implementer's text, which closes `docs/design/`.
- **Trailers:** every commit carries `Look-request: outside-pages`, one line directly above the other trailers (`temper/docs/design/draft/look-requests.md`, 3).
- **The account:** each task's last commit carries a table `| Item | Result |` (`look-requests.md`, 5): one row per item its spec gives it, landed and where, differs and why, or deferred and to whom; its last row the render check's, which follows landing, owned by temper/ui, since compiling, prints and focused tests establish no rendered equality.
- **Runs:** focused and fuzzy alone, each build and test through `heavy`, one command at a time. No `tools/tiers/run`, no `<tier>-<tree>` profile, no `scripts/browser.sh`, no browser story run, no walk, no render check, no screenshot, no throwaway driver: temper/ui's render check follows landing (`look-requests.md`, 4). A slow-tier crate a task touches is compiled alone (`heavy cargo check -p PKG --tests`).
- **Prints:** a task that changes the view's markup reprints the journeys whose pages change (`heavy cargo run -p temper-client-journeys`, no arguments, reprints the saved recordings; a recording it reports stale is recorded again with `again NAME`, the request's retries holding) and runs `heavy cargo nextest run -p temper-client-journeys`. A task that changes a stylesheet alone reprints nothing: the prints link `temper.css` by path. The gallery's print is made by its tests into a scratch directory and never committed.
- **Tests stay cheap:** no new test function; each case is a row or an assertion of an existing test, named in its spec. The gallery's tests are over their budget already (`temper/docs/design/client/browser.status.md`, 7.3): add nothing to them.
- **Before pushing:** `cargo fmt`; `python3 -I -B temper/scripts/old_forms.py`; `python3 -I -B tools/citations/citations.py --base origin/main`; clippy as the implementer's text says, naming every package changed.
- **Leave alone:** `origin/look-requests`; the drafts (`temper/docs/design/draft/*.md` and their status files); `docs/help/`; `temper/docs/design/client/journeys/overlay.css`; the GitHub App's setup pages (`temper/crates/temper-service/src/setup/`), which the request does not name.
