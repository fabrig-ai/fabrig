# tui-native-secret: what every task follows

- **The request binds:** `temper/docs/plan/tui-native-secret/inputs/request.md`, all of it, *For every task of this plan* first. It wins over a spec where they differ.
- **The contracts:** `temper/docs/plan/tui-native-secret/notes/contracts.md`, the names and shapes that cross this plan's tasks. Build to them; a change to one is a question.
- **The design this plan follows,** written by this cut: jig's `jig/docs/design/protocol/client.md`, 4.2 (the message `LocalLink`) and section 8, *The printed link* with its new *The local link*; `jig/docs/design/protocol/service.md`, section 7 (`jig-test` drops it); temper's `temper/docs/design/client/README.md`, 6.12 (*The engine's link, kept at rest*), 6.14 (*Answered `link_used` or `link_expired`*), section 7's first bullet and section 10's TUI joint world; `temper/docs/design/protocol/setup.md`, 13.4 (the box's story). Each task deletes the **Not yet** bullet naming it and `tui-native-secret` in the status file its spec names, and edits no other design text: that departs from the implementer's text, which closes `docs/design/`.
- **Two one-time links, one route.** The printed link and the local link are signed in by the same route and the same wire record (`LinkSignIn`); nothing on the wire, in `jig-client` or in the TUI's crates changes. The TUI's side is unchanged: it reads the file as it does today.
- **Runs:** focused and fuzzy alone, each build and test through `heavy`, one command at a time. No `tools/tiers/run`, no `<tier>-<tree>` profile, no `scripts/browser.sh`, no process, browser or live story run, no walk, no render check, no throwaway driver. The temper crate's `suite` binary (`temper/crates/temper/tests/suite/`) is focused, and its box stories run.
- **Tests stay cheap:** a new case of one behaviour is a row of an existing table; a new behaviour (two links live together) may take one new test function, named in its spec. A failing test first for each behaviour, as the request asks; the report names the rule broken by hand and the failure seen (the implementer's text, *A new test must bite*).
- **Never shown:** the local link's secret is never printed, logged, drawn or put in a panic or assertion message. A test compares it by equality and `contains`, and its messages name the link ("the file's link"), never its bytes.
- **Before pushing:** `cargo fmt`; `python3 -I -B jig/scripts/old_forms.py` and/or `python3 -I -B temper/scripts/old_forms.py` for each tree the branch touches; `python3 -I -B tools/citations/citations.py --base origin/main`; clippy as the implementer's text says, naming every package changed.
- **Leave alone:** the drafts (`temper/docs/design/draft/*.md` and their status files); `docs/help/`; the TUI's crates, `temper-client-tui` and `temper-client-shell-tui` (`post-landing-probes` is changing `host.rs` and the state and foot there); `jig-client` and the wire's schema; `temper/crates/temper/tests/fake_backends/**` and `temper/crates/temper/tests/support/**` (`walks-lower/walks-go` is changing them). A helper a story needs goes in the story's own file.
- **Decide, don't ask** (the request): a stored format, a protocol or a public interface may change before v0.1.0, with no compatibility or migration; a small edit just outside a spec's files is made and named in the report.
