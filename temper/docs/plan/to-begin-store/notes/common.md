# to-begin-store: standing rules

Every task of this plan names this note.

- Read `AGENTS.md`, then `temper/AGENTS.md`. This plan changes temper alone: no line of jig, smith
  or skein. A task that finds it needs one stops and asks.
- **The design is written.** Each task's `## Inputs` names the sections it builds; read those, never
  a whole design. The one `docs/design/` edit a task makes is the removal of its own **Not yet** text
  from the status file its spec names (a stated departure from the implementer's text, whose "Not
  yours" otherwise holds). Where the code teaches that the design is wrong, say so in the report;
  never change the design to fit.
- **The shapes that cross tasks** are `temper/docs/plan/to-begin-store/notes/contracts.md`, binding.
  A shape a task needs that it does not give is the spec's, or a question.
- **Changed in place** (`temper/docs/design/draft/to-begin.md`, 1): no supported deployment exists
  before v0.1.0, so the store's families, the FORGE records and `CLIENT_VERSION` change in place:
  `CLIENT_VERSION` stays 11, `STORE_VERSION` where it is, the schemas' headers as they are, no
  migration, no version kept for an older side.
- **Generated code and goldens** are regenerated by their writer, never by hand:
  `SKEIN_CODEGEN_WRITE=1 heavy cargo nextest run -p temper-codecs-world --test suite -E 'test(drift::)'`.
- **Build no "To begin" view and no "Skip" button.** Nothing shows a dismissal: no page, view, word,
  gallery sample or CSS changes for this plan.
- **Test worlds:** temper's crates' `src/tests/` and `temper/tests/...`. Fakes, never real services.
  Each test is one thread and one loop, and a seed replays (`AGENTS.md`, 2). No `live*` binary.
- **A budget or timeout of a test is the user's**
  (`skein/docs/foundation/testing-strategy.md`, 8.1): no task raises one.
- **Beside this plan:** `debt-11` (`map-busy`, `temper-clippy`, `temper-profiles`) and `debt-10`
  (`temper-names`) sweep `temper/crates/**`; `look-round-3` is on `temper-client-domain`'s and
  `temper-client-view`'s `pages/`, `frame.rs`, `forge/listed.rs` and
  `temper/docs/design/client/README.status.md`; `macos-cheap` is on `temper-forge-setup*` and
  `temper/crates/temper/`. Keep each edit in a file they touch to the lines the task needs: no
  reformatting, no moved code. Expect catch-ups; never rewrite their work.
