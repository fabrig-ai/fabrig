# box-small-2: the two things `box-small` missed

The user asked for these 2026-11-06, as additions to `box-small`. The answers reached its tasks while they ran, and neither was taken: at `box-small`'s trunk, `program_environment` still prints all three variables and nothing in `temper-box` writes OSC 8.

1. **Each variable prints only when it differs from its own default.** The user: "Re env variables of course they should be printed only if they are not the default path (~/.config/temper etc)". `program_environment` in `temper/crates/temper/src/directories.rs` is all or nothing: one directory off its default prints all three. So a box with only its data moved says `TEMPER_DATA=~/x temper program-login claude-owner`, and the defaults say nothing, as now. `temper/crates/temper/src/tests/program_environment.rs` and `temper/docs/design/client/README.md`, 4.6 follow.

2. **The box's sign-in link is clickable where the terminal can.** The user: "the sign-in URL printed by temper box should be clickable if the terminal supports it". Wrap the link in OSC 8 when the box's stdout is a terminal and `TERM` isn't `dumb`, the first link and every fresh one: `ESC ] 8 ; ; URL ESC \ URL ESC ] 8 ; ; ESC \`. The visible text stays the whole URL. Piped or sent to a file, stdout stays exactly as it is, the bare URL alone on its line, since scripts and tests read it (`temper/docs/design/protocol/setup.md`, the box's stdout). The line's bound then has to hold the URL twice plus the markers ("sign-in link too long" in `temper/crates/temper-box/src/terminal.rs`). An OSC 8 link stays whole across a wrapped line, where autodetection stops at the wrap and cuts the secret. Say so in `setup.md`, 7.2. emacs vterm ignores the sequence cleanly, by the laptop's check.
