# tui-link-colours: bare `temper` finds the engine's link, its note, and leaves the scheme to the terminal

## Goal

The `temper` binary's TUI start (`temper/crates/temper/src/tui.rs`) gives the run what
it now takes: the engine's link file of the deployment the environment names, for bare
`temper`'s address and for the sign-in; the note of the TUI's last sign-in at the chosen
address; the scheme where `COLORFGBG` decides it, else none for the terminal to be asked;
and a root for the run's own file.

Acceptance:

- As `temper/docs/design/client/README.md`, 6.11, *Bare `temper`*, and 6.12:
  - the link file's path: `link_file::path(link_file::deployment(&environment, cwd),
    XDG_RUNTIME_DIR, cfg!(target_os = "linux"))`, `cwd` the working directory's bytes,
    `XDG_RUNTIME_DIR` from the environment; none when either is none;
  - the address, by a pure function of your naming beside `address` and `kept`, tested as
    a table: ADDRESS given wins; else the file's link's engine when `link_file::read`
    gives a link that `open::target` reads as a link on loopback; else the kept
    `address`; else `http://127.0.0.1:8367`. A file that reads as anything else is
    ignored, saying nothing;
  - the note: `DIRECTORY/sign-in` read once as a private file (skein-shell's
    `read_private_file`, `Note::MOST`), `Note::read(bytes, HOST:PORT)` for the chosen
    address, none for any refusal;
  - the scheme, `scheme(environment) -> Option<Scheme>`: `COLORFGBG`'s last field, after
    its last `;`, a decimal number: `Light` for 7 or 15, `Dark` for any other; absent,
    empty or not a number: none (README.md, 6.15, *The scheme*);
  - `run::Settings`: `scheme`, `link_file` (the path's bytes), `note`, and `files`, the
    TUI directory's parent opened as a root once more (`skein_shell::open_root(parent)`),
    closed as the others are on a refused start.
- `commands.rs`: the `temper [ADDRESS]` argument's line says the default as 6.11 now
  does: "...; by default the address of the engine's link file its environment names,
  else the address the TUI last signed in to, else http://127.0.0.1:8367." or words as
  short; `temper/docs/help/reference/commands.md` regenerated by its own test
  (`src/tests/commands.rs`, with `SKEIN_CODEGEN_WRITE=1` as that test says), within its
  bound.
- Rows in `src/tests/tui.rs`, each a failing test first:
  `the_scheme_and_the_depth_follow_the_environment`'s `COLORFGBG` rows become: `0;15`
  `Some(Light)`, `15;0` `Some(Dark)`, `7` `Some(Light)`, `0;default;8` `Some(Dark)`,
  `default;default` none, empty none, absent none; a new table for the address: given,
  file, kept and default, a file holding an address rather than a link, a link off
  loopback and garbage each ignored; the path agrees with what `link_file::path` gives
  the box for the same environment's data directory (one row, since `box-side`'s tests
  hold the table); the note read for its own address and none for another's.
- Rows in `src/tests/tui.rs` must not read a real `XDG_RUNTIME_DIR`, `HOME` or data
  directory: the pure functions take the environment and paths given.

- Owns the files in `files`. `link_file.rs` is `box-side`'s, landed: call it, and change
  it only for a call site's need (say so).
- `scheme`'s return type changes: its reader is `tui.rs` alone, and the test.
- If `open::target` reads the file's link with its secret, keep nothing of the secret:
  only the engine's address leaves the function.
