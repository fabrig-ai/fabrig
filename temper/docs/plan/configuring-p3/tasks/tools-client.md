# tools-client: a charter's tools through the client wire and the settings file

## Goal

A charter's `tools` (contract C1) crosses the client wire and temper's settings file both
ways: `settings show charter N` prints it, a settings file and a run's `propose_settings` set
it, and a file that leaves it out gets `1023`, every family but settings. With
`tools-store`, a charter's mask is then carried end to end, and jig's `engine.status.md` 7.1
entry for it closes.

Acceptance:

- `jig/crates/jig-client-protocol-wire/schema/client-v19-part1.schema`, `record Charter`,
  gains `tools: u64` after `call_timeout`, in place (client-v19 stays), its generated code and
  goldens regenerated by the client wire's drift test, never by hand.
- `jig_client_domain`'s contract `Charter` (`contract/settings.rs`) gains `pub tools: u64`
  after `call_timeout`; every translator carries it both ways, in place of `tools-surface`'s
  `EVERY_FAMILY` filler: `jig-protocol-engine-clients`' core-to-wire (`translate/settings.rs`)
  and wire-to-core (`translate/settings/change.rs`), `jig-client-protocol-link`'s
  (`translate/settings.rs`, the charter and its restore), the scripted engine's and the test
  records'.
- temper's settings form: the neutral `Charter` (`view.rs`) gains `tools: u64`; the settings
  file's charter takes an optional `"tools"` integer (`settings_file_values.rs`), left out
  `CHARTER_TOOLS_DEFAULT` (`pub const CHARTER_TOOLS_DEFAULT: u64 = 1023;`, documented "Every
  jig family but settings: a charter's `tools` when its file leaves it out"); `encode_charter`
  (`values.rs`) writes it after `call_timeout`; `wire.rs` carries it both ways;
  `temper-client-tools`' `settings_adapter.rs` carries it in `form_charter` and
  `client_charter`.
- `FIELDS` (`temper-settings-form/src/fields/jig.rs`) gains the charter's `tools` row after

  families its runs are offered, a bit each as an authority's `tools` has them; a family it or

  becomes 191 rows; `temper/docs/help/reference/settings-fields.md` is regenerated from it
  (the stated `docs/help/` departure: the page is rendered, never written by hand).
- Tests: in `temper-settings-form`, `a_charters_tools_round_trip` (a file's charter with
  `"tools": 1536` decodes, goes to the wire and back, and encodes with the same member) and
