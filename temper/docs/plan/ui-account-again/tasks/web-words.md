# The web says why a refused account act was refused, and what to do

## Goal

The web's account acts draw jig's refusal word alone ("This act is not
offered") where the refusal has one reason a person can act on. Draw the
reason and the next step for the three cases ctl words too. Move
`ConnectModel`'s own-name recovery from *not offered* to *name taken*,
which is the refusal the engine now gives a declaration of a taken name.

Acceptance:

- One new table test in
  `temper/crates/temper-client-view/src/tests/accounts.rs` (or in
  `tests/connect_model.rs` if the declaration rows' fixtures live only
  there; then the resume row goes beside its siblings in `accounts.rs`),
  `account_act_refusals_say_why_and_what_next`, one row per line of
  `notes/contracts.md`, section 6. Each row sends the act from its page
  (a declaration from `ConnectModel`'s program panel, "I've signed in";
  a resume from an account's row on `Accounts`), answers it refused
  through the client's `Up::Answer`, as `paste_case` in
  `tests/connect_model.rs` does, and asserts the outcome line's text,
  byte for byte, NAME the declared name.
- A fourth row: a declaration refused `c::Refusal::Unknown` still draws
  `crate::cards::refusal`'s words, unchanged.
- `temper-client-domain`: in `pages/connect_model.rs`'s `told`, a
  declaration refused `c::Refusal::NameTaken` whose name is the person's
  own program source with that provider (`program_source`) sends that
  source's check, as `NotOffered` does on the base; `NotOffered` no longer
  does. `welcome_claude_recovers_an_issued_name_and_resets_when_the_way_changes`
  in `src/tests/pages/connect_model.rs` scripts `NameTaken`, and gains one
  row (or an assertion in the same test) that a declaration refused
  `NotOffered` sends no check and leaves the page idle.
- With the person's own source holding the name, the page draws no
  refusal (the check replaced the request): the view row for *name taken*
  delivers an `accounts` document without that source.
- Every other test in both crates still passes; clippy and fmt clean.
