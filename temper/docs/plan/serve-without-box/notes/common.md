# serve-without-box: standing rules

Every task of this plan names this note.

- Read `AGENTS.md`, then `temper/AGENTS.md`. temper names jig, smith and skein; none of them
  names temper. This plan changes temper alone.
- **The design is written.** Each task's `## Inputs` names the design sections it builds, by
  path and section; read those, never a whole design. The one `docs/design/` edit a task makes
  is the removal of its own **Not yet** text from the status file its spec names (a stated
  departure from the implementer's text, whose "Not yours" otherwise holds); no other design,
  draft or `docs/help/` edit unless the spec names the file. Where the code teaches that the
  design is wrong, say so in the report; never change the design to fit.
- **The shapes that cross tasks** are `temper/docs/plan/serve-without-box/notes/contracts.md`,
  binding. A shape a task needs that it does not give is the spec's, or a question.
- **The client wire changes in place** (`temper/docs/design/client/README.md`, 4.6):
  `CLIENT_VERSION` stays 11; a read added changes the schema, the generated code and one set of
  golden bytes, regenerated by their writer, never by hand:
  `SKEIN_CODEGEN_WRITE=1 heavy cargo nextest run -p temper-codecs-world --test suite -E 'test(drift::)'`.
- **Generated help:** `temper/docs/help/reference/configuration.md` and
  `configuration-engine.md` are what the tables render:
  `SKEIN_CODEGEN_WRITE=1 heavy cargo nextest run -p temper --lib -E 'test(=tests::configuration::the_pages_configuration_are_what_the_tables_render)'`.
  Check the test's path with `heavy cargo nextest list` if the filter selects nothing. A task
  that changes a member row regenerates them, a stated departure from "Not yours".
- **No existing deployment is carried over** (the draft, 2): no migration, no compatibility
  branch, no reading of an old form.
- **Nothing changes under the box:** the welcome, the playground with its "Demo" and its reset,
  and Ready's "Default" stay as they are. A test that runs a box and finds them still finds them.
- **Test worlds:** temper's crates' `src/tests/`, `temper/crates/temper/tests/` (the `suite`
  binary) and `temper/tests/engine/...`. Fakes, never real services; no test reaches a network,
  a held login or a real repository. Each test is one thread and one loop, and a seed replays
  (`AGENTS.md`, 2).
- **Never run a live story:** no test of a `live*` or `proof_live` binary.
- **A budget or timeout of a test is the user's** (`skein/docs/foundation/testing-strategy.md`,
  8.1): no task raises one.
- **Beside this plan:** `debt-7` moves `temper-service`'s hosts (`temper-service/src/**`) and
  `live-login-guard` touches `temper/crates/temper/tests/{process.rs,suite/startup.rs}`. Keep each
  edit in those files to the lines the task needs: no reformatting, no moved code. On a merge
  conflict with them, say so in the report; never rewrite their work.
