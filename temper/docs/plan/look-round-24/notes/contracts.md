# look-round-24: the shapes that cross tasks

Binding for every task that cites this note. `ways-wire` lands the wire and engine surface first; the tasks after it build on it, each on its own side.

## The wire (`temper/crates/temper-client-protocol-wire/schema/client-wire-v1.schema`)

```text
record Fact { label: text 32 value: text 184 }              # was text 128
record OpensGate { number: u32 charter: u32 }               # charter: the gate's reviews' charter
record RuleView { kind: u32 number: u32 card: Card }        # new, beside CharterView
enum View { way: WayView, path: BranchPath, proposal: ProposalView, charter: CharterView, rule: RuleView, not_drawn: NotDrawn }
```

`rule` sits after `charter` in `View`'s order. No family version changes: the stored and recorded encodings of every other record stay as they are (`README.md`, 4.6, *Bounds*). The generated code and goldens are regenerated by the drift test alone:

```sh
SKEIN_CODEGEN_WRITE=1 heavy cargo nextest run -p temper-codecs-world --test suite -E 'test(=drift::client_wire_schema_matches_generated_code_and_goldens)'
```

## The engine (`temper-engine-domain-ways`)

```rust
// path.rs
pub enum Opens { Nothing, Charter(u32), Rule { kind: u32, scope: u32, number: u32 }, Gate { number: u32, charter: u32 }, Tier(Box<[u8]>), Queue, Turn }
pub const VALUE: usize = 128; // a fact's value, but an agent's "Asked to"
pub const ASKED: usize = 184; // an agent's "Asked to", its quotes included

// ways.rs
pub enum View { Way { .. }, Path(Path), Proposal { .. }, Charter { charter: u32, card: Card }, Rule { kind: u32, number: u32, card: Card }, NotDrawn(Box<[u8]>) }

// words.rs (asked-sentence)
/// The first sentence, trimmed; whole when it fits `bound` bytes, else cut at the
/// last word's end that fits with "…" (three bytes) after it (forge.md, 8.13).
pub fn first_sentence(instructions: &[u8], bound: usize) -> Box<[u8]>;
/// `value` whole when it fits `bound`, else cut at the last word's end that fits with "…".
pub fn cut_on_word(value: &[u8], bound: usize) -> Box<[u8]>;

// path.rs (ci-workflows): `Repository` gains, after `checks`,
pub contexts: Box<[Box<[u8]>]>, // the landing branch's required checks, as the forge's protection holds them
```

`Opens::Gate`'s `charter` is the reviews' charter the derivation already names for the gate's stop (`derive.rs`, the review's `agent_card(inputs, charter, ...)`). The service maps it to `OpensGate { number, charter }` and `View::Rule` to `w::View::Rule(RuleView { kind, number, card })`.

## The view address (`temper-engine-domain`, `route/ways/view/address.rs`)

`rule K/N`: the word `rule`, then one word `K/N`, `K` 1 or 2, `N` a natural (no zero, no leading sign), no `@revision`. Anything else beginning `rule` is `Unknown`. `K` 1 is the deployment's rule N (scope 0), `K` 2 the chat's or page's project's rule N.

## The client (`temper-client-domain`)

```rust
// address.rs
Address::Role { project: u32, charter: u32 }               // /projects/<project>/settings/roles/<charter>
Address::Rule { project: u32, kind: u32, number: u32 }     // /projects/<project>/settings/rules/<kind>/<number>
```

`kind` decodes 1 or 2 alone; `charter` and `number` a natural; any other is no address, as the codec's other paths refuse. Both pages read the forge's `View` read (`w::Read::View(ViewRead { project, address })`) with the address `charter N` or `rule K/N`, as `pages/chat/views.rs`'s `reading` builds it, and keep its answer's `w::View`.

## The text shell (`skein-ui-text`)

A node whose line would be `NAME:` alone, where the nearest ancestor that printed such a line printed the same `NAME:`, prints no line and indents its children no further (`skein/docs/design/ui-text.md`, 5).
