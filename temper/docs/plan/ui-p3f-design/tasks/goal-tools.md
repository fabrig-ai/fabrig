# `temper ctl settings show template-goal N`, and a proposal card's name for kind 11

## Goal

A person reads and writes a goal template's work with ctl, as they do the forge's
charters: `settings show template-goal N`, with `--revision` and `--json`, and
`settings apply` and `settings propose` taking a `template-goal` item; `settings
show` lists it by name. A proposal card names a kind 11 item `template-goal N`
rather than "application kind 11".

Acceptance, by `temper/docs/design/client/tools.md`, 5.3 (its table's
`settings show template-goal` row and *A goal template's work*):

1. **ctl's show,** as `temper/docs/plan/ui-p3f-design/notes/contracts.md`,
   section 8, has it, built as `settings show forge-charter` is: `design` and
   `close_out` from the forge's `Setting { kind: 11, scope: 0, number }` read,
   the stock's marked as `forge-charter`'s default is; with none held, `none
   kept`; with `--revision R`, the value that revision set; with `--json`, the
   value in the form `settings apply` takes (`goal-kind`'s settings form).
2. **ctl's names:** `settings show` lists kind 11 as `template-goal N`; the
   file's and `proposal show`'s items name it so, through the settings form as
   `forge-charter` reaches it.
3. **The card** (`temper/crates/temper-client-view/src/cards/proposal.rs`,
   `setting_base`): an arm `c::Setting::Application { kind: 11, number, .. }`
   giving `template-goal` and the number, on the line right after the `kind: 3`
   arm; nothing else of the card.
4. **Help:** `temper/docs/help/settings.md` names `template-goal N` where it
   names `forge-charter N`, within its bound; `temper/docs/help/reference/ctl-settings.md`
   regenerated by its test (`notes/common.md`).
5. **Rows,** no new test function:
   - `temper/tests/client/tests/suite/settings_tools.rs`, the story of each kind
     through ctl (its table with `forge-charter 1`): a `template-goal 4` row,
     set to both, shown, shown as JSON and read back; and in the listing that
     checks `landing-rule` and `forge-charter` by name, `template-goal`;
   - `temper-client-tools/src/tests/jig/settings.rs`, where `forge-charter`'s
     selector is parsed: a `template-goal` row;
   - `temper-client-view/src/tests/cards.rs`, the table naming settings
     (`project-ways 1` among them): `(Application { kind: 11, scope: 0, number:
     4 }, b"template-goal 4")`.
6. **Bite:** drop the card's arm, see its row fail; restore.
7. **Status:** delete the bullet naming `goal-tools` in
   `temper/docs/design/client/tools.status.md` (5.3) (`notes/common.md`, *Status
   files*).
