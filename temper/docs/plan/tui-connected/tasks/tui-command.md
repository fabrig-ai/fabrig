# Bare `temper` and `temper ADDRESS` run the TUI

## Goal

The binary's part of the TUI: bare `temper` in a terminal, and `temper
ADDRESS`, run it at the address kept, the default or the one given, from
its own private directory, with the scheme and colour depth the terminal's
environment declares, the input raw and a panic's restoration set; without
a terminal, bare `temper` prints the line it prints today. The command
table gains its row, and the generated reference page follows.

Acceptance:

1. **The row:** `commands::COMMANDS` gains, first among `Who::Clients`
   (`temper/docs/design/protocol/README.md`, section 4's order),
   `Row { words: &[], who: Who::Clients, forms: &["[ADDRESS]"], line:
   "Run temper's full-screen terminal client, the TUI, on an engine.",
   arguments: &[Argument { shown: "ADDRESS", line: "The engine's clients'
   listener, http://HOST:PORT on loopback; by default the address the TUI
   last signed in to, else http://127.0.0.1:8367." }], settings: &[],
   notes: "Needs a terminal on stdin and stdout; without one, bare temper
   says it has no command. Its sign-in link is pasted on its screen, never
   given. Its directory is $XDG_STATE_HOME/temper/tui, else
   ~/.local/state/temper/tui. q or Ctrl+C closes it without signing out." }`.
   `find` gives it only for no words or a first word beginning `http://`;
   every other first word no row continues is `unknown`'s, as today.
   `forms`, `refused`, `help`, `row` and `reference` write a row with no
   words as `temper [ADDRESS]` and `temper: WHY`, with no doubled space.
2. **The parse:** `crate::Command` gains `Tui { address: Option<Box<[u8]>> }`;
   `configure_row` gives it for no argument or one, and refuses two or
   more (`temper: invalid arguments` and `usage: temper [ADDRESS]`).
   `run` runs `tui::run(address, &Clock::new())`.
3. **`temper/crates/temper/src/tui.rs`** is `notes/tui.md`, section 6:
   `Refused` and its `line` (the lines of
   `temper/docs/design/client/README.md`, 6.11's table, each ending
   `\n`), `address`, `directory`, `kept`, `scheme`, `depth`, and `run`:
   1. stdin and stdout both terminals (`skein_shell::terminal_modes` on
      `Fd::new(0)` and `Fd::new(1)`), else: bare, `commands::unknown(&[])`'s
      line on stderr and 1; with ADDRESS, `Refused::NotATerminal`'s line
      and 1;
   2. ADDRESS through `address` (`open::target`: a link is
      `Refused::Link`, an address off loopback `NotLoopback`, anything else
      not an address `NotAnAddress`);
   3. the directory (`directory`), made and checked private with
      `directories::make_private`; refused, `Refused::Directory`;
   4. bare: the `address` file read with `skein_shell::read_private_file(..,
      64, user)` and `kept`; none, `127.0.0.1:8367`;
   5. the scheme and the depth from `skein_shell::environment()`;
   6. `skein_shell::raw_input(Fd::new(0), Keys::Pass)`: `Input::Terminal {
      kept, size }`, else `Refused::NotATerminal`;
      `skein_fail_stop::before_report(Some(kept.on_abort(Fd::new(1),
      skein_ui_screen_terminal::LEAVE)))`;
   7. the signals, `skein_shell::open_signals(Watch::TerminationAndWindow)`;
      the directory's parent opened (`skein_shell::open_root`); the run
      (`temper_client_shell_tui::run::Run::new` with `run::Settings {
      engine: skein_io::Addr::Ip(address), directory: b"tui", address:
      HOST:PORT, scheme, depth, size, limits: limits::tui() }`, the root,
      the effective user, `skein_shell::seed()`, `Fd::new(0)`, `Fd::new(1)`,
      the signals); a kernel of its operations; `skein_shell::drive`;
   8. `skein_fail_stop::before_report(None)`, then `kept.restore()`;
   9. `run.refused()`: `temper: DIRECTORY: cannot open its files` on
      stderr; `run.signed_in()` an address the file did not hold: the
      file written with `skein_shell::store_file` (`notes/tui.md`, section
      6: `StoreDirectory::Private { name: b"tui", user }`, the bytes
      `http://HOST:PORT`, `Expect::Any`, a timeout of 5 s) on a kernel of
      `skein_shell::STORE_OPERATIONS`, its failure ignored;
   10. the exit: `Exit::Code(code)` its code, a signal's 1.
4. `temper/docs/help/reference/commands.md` regenerated by its test
   (`SKEIN_CODEGEN_WRITE=1`), its diff the new row alone.
5. Unit tests (Steps, 3), every row named in the report.
