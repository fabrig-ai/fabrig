# change-row-llm: a change's row keeps its LLM choices, and its delegates take them

## Goal

The change's row keeps an LLM choice per role beside its two charters (contract C4): the
producer's, for its producing task, repairs, resolutions and checks' gates, and the reviews',
for its agents' gates. temper's store keeps them (a format change of store version 11, in
place: `temper/docs/design/protocol/store.md`, section 4), and every delegate the change asks
for is given its role's choice as its `llm`. Every change made today has neither, so behaviour
is unchanged until task `change-root` sets them.

Acceptance:

- `temper_engine_domain_forge::boundary::ChangeRow` gains, after `review_charter`:

  ```rust
  /// The LLM choices by role it was made with (domain/forge.md, 8.1 and 8.9).
  pub producing_llm: Option<jig_domain_tasks::LlmChoice>,
  pub review_llm: Option<jig_domain_tasks::LlmChoice>,
  ```

- temper's schema `store-v11.schema`: `ChangeRow` gains `producing_llm: option LlmChoice
  review_llm: option LlmChoice` after `review_charter`, with `record ModelEffort { model: u8
  effort: option u8 }` and `record LlmChoice { main: ModelEffort subagents: list 64
  ModelEffort account: option u32 }` (jig's shape, `jig/crates/jig-protocol-store/schema/
  tasks-v9.schema`, field for field; reuse the records if the schema already has them).
  `STORE_VERSION` stays 11; the generated `v11.rs` is regenerated by skein-codegen, never
  edited by hand; the golden bytes are regenerated as the crate's golden tests say; the
  translations in `records/change.rs` are total both ways.
- `temper-engine-domain`'s `route/forge_route.rs`, `change_delegate`: the delegate's `llm` is
  `row.producing_llm.clone()` for `Produce`, `Repair` and `Resolve`, and for a gate the role
  its executor runs: `row.review_llm` for an agent gate (the review charter), `row.producing_llm`
  for a check gate (the producer's charter), none for a person gate. `start_change`'s row
  literal sets both `None`.
- A round trip of a row with both choices, sub-agents and efforts, and with neither, is equal
  to itself; a change whose row names a choice makes its producing task with it (a unit test
  in `temper-engine-domain/src/route/forge_route/tests.rs`).
