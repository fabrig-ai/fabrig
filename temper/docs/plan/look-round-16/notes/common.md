# look-round-16: what every task follows

- **The request binds:** `temper/docs/plan/look-round-16/inputs/request.md`, all of it, *For every task of this plan* first. It wins over a spec where they differ.
- **The procedure:** `temper/docs/design/draft/look-requests.md`, 3 and 5. The requests are four commits on `origin/look-requests`, in this order, each found by its trailer, since the branch moves: `git log origin/look-requests --grep='Look-request: NAME'`.
  - `chat-terminal` (`060312d7e8` when cut): the terminal, its commands and its states.
  - `chat-terminal-font` (`e08fc0004f`): DejaVu Sans Mono at 11pt, `/font`, the fonts.
  - `chat-terminal-draft` (`66b3894988`): the draft beside it as a document; emphasis in a draft.
  - `chat-terminal-esc` (`e8dd3197b5`): Esc in full screen.
  Read a request with `git show` alone, its whole message first: `temper/docs/design/client/journeys/chat-terminal/` holds its pages `01.html` to `06.html`, `README.md`, `terminal.css`, `terminal.js` and `fonts/`, as each commit leaves them. `chat-title`, below them, is another plan's (`look-round-15`); nothing of it lands here.
- **The design this plan follows:** `temper/docs/design/client/README.md`, 3.5, *A chat's terminal*, and `temper/docs/design/client/browser.md`, 2.5, *The terminal's look*; skein's `ui.md`, 10 and the sections a spec names. Where a request's page and the design differ, the design was written from the request and wins; say what you found in the report.
- **Trailers:** every commit carries the trailer of the request its change lands, one line directly above the other trailers, a fix of what an earlier commit missed included. A task that lands two requests' changes splits its commits by request. A skein task's commits carry the trailer of the request it serves, as its spec says.
- **Runs:** focused and fuzzy alone, each build and test through `heavy`, one command at a time. No `tools/tiers/run`, no `<tier>-<tree>` profile, no `scripts/browser.sh`, no browser story run, no walk, no render check, no screenshot, no throwaway driver: temper/ui's render check follows landing (`look-requests.md`, 4). A browser-tier story a spec allows is compiled with `heavy cargo check -p PKG --tests`, never run.
- **Tests stay cheap:** a new case of a behaviour is a row of the table test that holds it; a spec names each new test it allows, and no task adds a browser story.
- **Prints:** a view change that moves a recorded journey's pages is reprinted by `temper-client-journeys` with no arguments (`temper/docs/design/client/journeys.md`, 5 and 8); `temper-client-journeys again NAME` only where a recording itself goes stale (none should in this plan). The gallery's `names.txt` stays sorted; a catch-up regenerates prints and goldens rather than hand-merging them.
- **`temper.css`:** this plan's rules go under `/* ==== ui: chats ==== */`, never at the file's end; `@font-face` rules go beside the file's other `@font-face` rules. Remove a rule a change replaces where it stands.
- **Look tokens:** `temper-client-view/src/look.rs`'s `NAMES` is indexed by token, so a new token takes the next number and its name at that index. Another draft (`ui-forge-identity/approval-card`) also adds tokens there: whichever merges second renumbers its own and says so.
- **Before pushing:** `cargo fmt`; `python3 -I -B <tree>/scripts/old_forms.py` for each tree the branch touches; `python3 -I -B tools/citations/citations.py --base origin/main`.
- **Leave alone:** `origin/look-requests` and every file under `temper/docs/design/client/journeys/chat-terminal/` (the requests' pages stay on that branch; the fonts are copied out of it, never moved in git), `overlay.css`, the drafts, `docs/help/` but where a spec says, and `temper-client-shell-terminal`, the terminal client of `temper open`, which this plan does not change.
