# ctl's `project amend --visibility` and `project show`'s public page

## Goal

An owner makes a project public or private again from `temper ctl`, and reads whether it is
and where its public page is (`temper/docs/design/client/tools.md`, 5.2 and 5.3): `project
amend PROJECT --visibility public|private` sends jig's `SetVisibility`, keyed, and prints the
answer with the public page's path from `me`'s public identifier; `project show` says whether
the project is public and, if so, its page's path. The help pages say so.

Acceptance:

- A tool `project amend`, appended last to the tools table (`table.rs` `TOOLS`, after
  `rows::GOAL_START`), its position `rows::PROJECT_AMEND_AT: u8 = 63` (the next after
  `GOAL_START_AT = 62`; if 63 is taken on your base, the next free one, and say which):
  `project amend PROJECT --visibility public|private --key KEY`, `PROJECT` as `project fund`'s
  (`Kind::Project { empty: false }`), `--visibility` a required
  `Kind::Word { set: &[b"public", b"private"] }`, `keyed: Keyed::Required`, `area: 1`, result
  `project_amend`, its `line`, `prints` and `notes` in tools.md 5.3's words (the notes say
  that a member and project 0 are refused, exit 2, and that the page is a path under the
  deployment's address).
- It sends `jig_client::contract::Ask::SetVisibility { project, public }` (contracts 2), the
  project resolved from `me` as `project fund`'s is (`runner/reads.rs` `project`); an unknown
  project prints `unknown project`, exit 1, as `project fund` does, sending nothing.
- Answered done, it prints, once `me`'s entry for that project agrees with the answer (its
  `MeProject.public` is `Some` when made public, `None` when made private):
  - text, made public: `project 1: public` then `page: /public/projects/3f2a9c01d4e5b6a7`,
    one line each; made private: `project 1: private`;
  - `--json`: `{"answer":{"project":1,"public":true,"page":"/public/projects/3f2a9c01d4e5b6a7"}}`,
    `"page":null` when private.
  The identifier prints as exactly 16 lowercase hexadecimal digits, zero-padded
  (`temper/docs/design/client/browser.md`, 8.1; jig's `domain/people.md`, 13.8).
  If `me` does not yet agree when the answer arrives, the call waits for `me`'s next change
  (the runner's `Told::Changed` for `runner.me()`), within the call's own wait, and prints
  then; it never prints a page `me` does not carry.
- A refusal (a member's, project 0's, a project being deleted) prints as every refused act
  does (`render/outcome.rs`), exit 2; a key's replay prints the first answer.
- `project show` gains one line after its first (`project 1, shop`): `public: no`, or
  `public: /public/projects/3f2a9c01d4e5b6a7`, from `me`'s `MeProject.public` for that
  project; its JSON gains `"public"`, the path or `null`, right after `"number"` in the
  project's object, outside the subject's digest (the digest is the project document's and
  stays as it is). `project fund`'s output is unchanged.
- `temper/docs/help/project.md` says how a project is made public and private again and what
  that means (in "How it changes", "Acting on it" and "Limits": anyone reads a public
  project's tasks' structure, never its words or names, through the public pages; only an
  owner changes it; project 0 never), in the page's style; `docs/help/reference/ctl-project.md`
  is regenerated by `the_project_reference_is_what_the_table_renders` with
  `SKEIN_CODEGEN_WRITE=1`, never by hand.
- Goldens in `src/tests/golden/`: `help_project_amend.txt` (in `tests/help.rs`'s list),
  `project_amend.txt`, `project_amend_json.txt`, and `project_show.txt` /
  `project_show_json.txt` updated.
- Step tests (in `src/tests/jig/`, a new `visibility.rs` beside `projects.rs`, declared in
  `src/tests/jig.rs`):
  - `project_amend_sends_set_visibility_under_its_key`: both values, the project by number and
    by name; the sent ask and its key's name;
  - `project_amend_needs_a_key_and_a_visibility`: either missing, or `--visibility open`, is
    usage, nothing sent;
  - `made_public_prints_the_page_from_me`: the answer, then `me` with `public:
    Some(0x00ab_0000_0000_0001)`: prints `page: /public/projects/00ab000000000001`;
  - `the_page_waits_for_me_to_agree`: the answer arrives while `me` says `None`; nothing
    printed until `me` changes, then the page;
  - `made_private_prints_no_page`;
  - `a_refused_visibility_exits_2`: a scripted refusal of a member's `SetVisibility`;
  - `project_show_says_whether_it_is_public`: both, text and JSON, against the goldens;
  - `an_unknown_project_sends_nothing`.
