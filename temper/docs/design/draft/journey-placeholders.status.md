# journey-placeholders: status

2026-11-17. Where the design lags or departs from [journey-placeholders.md](journey-placeholders.md).

- **Design departs:**
  - 2: the draft's "two recordings of one journey are byte-identical, prints included" is not a placeholder's to keep: no placeholder takes a time. A wall time stands, since a page draws a time in forms no substitution maps back and the engine's times are bare numbers inside wire bytes, so a shifted clock can be neither found whole nor proved. A print reads the recording's clocks, never the printing host's, so one recording prints the same bytes on any day (`../client/journey-placeholders.md`, 2.4). Agreed by the user on 2026-11-17.
  - 2: a framed field's length doesn't follow a placeholder of another width. The wire's lengths nest, and only its schemas know where they are; such an original stands everywhere instead, and `add` names its kind and counts it. No committed journey has one (`../client/journey-placeholders.md`, 3.3). Agreed by the user on 2026-11-17.
  - 2: the first replay's proof runs on the redacted recording, before it is normalised, and the check runs on the normalised recording, which is printed; nothing is written unless it holds. A terminal frame lays out by width, so a fixed build placeholder can't be substituted into the live frames (`../client/journey-placeholders.md`, 4.1). Agreed by the user on 2026-11-17.
