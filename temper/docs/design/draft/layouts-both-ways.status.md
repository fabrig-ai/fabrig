# layouts-both-ways: status

2026-11-27. Where the design lags or departs from [layouts-both-ways.md](layouts-both-ways.md).

- **Design departs:**
  - 4.2: in Keep mode, an absent `option` that the target takes away is refused, where the table has Keep do as Read and take the target's default (`skein/docs/design/data/codec/layouts.md`, 2). Writing the default would come back present by the Read plan, so the value would not mean the same at the target, against 4.2's Keep, and 4.5's round trip would not hold. Decided by goal L1's designer, 2026-11-24, where two of the draft's lines contradict.
  - 3: a client's exchanges that wait for no hello, signing in and out, approvals and the link's asks, are judged by no layout: at another layout, one whose own records changed may be refused unnamed, where *version not served* named it before (jig's `protocol/client/versions.md`, 1 and 2). Decided by goal L4's designer, 2026-11-24: the draft compares layouts at the hello, which those exchanges don't wait for, and a record whose declarations are unchanged decodes alike at either layout; reads, the one other exchange that left before the hello, now wait for it.
  - 4.4: the store reads a value a task log or a transcript holds at a layout older than the binary's by its derivation, the Read mode with every part a value could be refused at refused as the plan's, so those plans and refusals are as before (`skein/docs/design/data/codec/layouts.md`, 2). The open walks no log and no frame, and nothing writes such a value again, so a value its Read plan refused would be met only when read. The map's older layouts are read by their Read plans, each value of one that may refuse checked at open (`jig/docs/design/protocol/store/layouts.md`, 5.3 and 5.6). Decided by draft-5's request, 2026-11-25.
  - 4.4 and 8.1: a store opened by an older build keeps by Keep plans the map's values alone, each checked at open; a value a task log or a transcript holds at a later layout is read by its Read plan, and the check does not walk them (`jig/docs/design/protocol/store/layouts.md`, 5.6). Nothing writes such a value again, so the log or the file keeps what the older build skips, while a check over every log and frame would read most of the store at every open. Decided by goal L2's designer, 2026-11-24, keeping 8.1's intent that going back loses nothing committed.
  - 8.2: settling puts its values in the root's commits rather than commits of its own, since every commit while the store serves is one the root numbers (`jig/docs/design/protocol/store/commits.md`, 1); and it retires each layout its walk empties, in place of the next open, since no open writes for retirement alone and a checkpoint's open refuses one that must write (`jig/docs/design/protocol/store/settling.md`, 3 and 4). After it, the registry holds the binary's layouts alone for the map's value types; a log's and the frames' layouts stay while a log or a transcript may hold them. Decided by goal L2's designer, 2026-11-24.
  - 8.3: a frame names two layouts, its body's and its turn's, each by its own head, where a registered value names one with its held records in it (`jig/docs/design/protocol/store/transcripts.md`, 6). Frames written before the registry hold turns at two versions under one body version, and no frame is rewritten, so one id could not name both. Decided by goal L2's designer, 2026-11-24.
  - 5: a worker sends every wire's text in every credential, not only those whose fingerprints differ (`jig/docs/design/protocol/channel/wires.md`, 2), and the engine accepts with the worker's kinds' table (`skein/docs/design/net/channel.md`, 5.2). The worker cannot know which differ before the engine answers, and the engine needs the worker's table before it accepts; a text still travels once per connection. Decided by goal L3's designer, 2026-11-24, where the draft's letter cannot hold and its intent is kept.
  - 3 and 6: `smith-pieces` is compared at the opening and never converted: the engine keeps a call's name and a delivery's evidence as bytes that name no layout, so a worker whose layout of it differs is refused by name (`jig/docs/design/protocol/channel/layouts.md`, 2.1). Decided by goal L3's designer, 2026-11-24, since 2's table puts the pieces with smith's channel, and converting them on the wire alone would leave stored ones misread.
  - 7.1 and 7.3: one kind of written converter serves a stored value and a sent one: its owner writes one function for a value type, from one layout to another given both texts, which the store's written jobs call for each value they walk and the engine calls where that value type's plan would run (`skein/docs/design/data/codec/layouts.md`, 4; `jig/docs/design/protocol/store/jobs.md`, 4; `jig/docs/design/protocol/channel/layouts.md`, 6), where 7.3 has a pair of functions named by both fingerprints for a wire and a written job for the store. The engine holds the value and asks its owner through the service, since step code calls no function an owner hands in, and a wire's owner declares the worker layouts its converter takes. Decided by draft-5's request, 2026-11-27.
  - 3: `versions` prints the host tools' contract apart from the wires, `contract temper-host-tools FLOOR CURRENT`, with its floor and its version (`temper/docs/design/protocol/wires.md`, 10), where 3 has every line a family's fingerprint: the contract is a text with versions of its own, outside the codecs (10), whose older versions the engine answers for a run adopted across a restart (`temper/docs/design/protocol/wires.md`, 7). No frozen family's version is read or printed as a range. Decided by goal 21021's designer, 2026-11-27, keeping the request's intent.
  - 3: the landing that switches the worker wires to plans, L6's, changes the workers' opening itself, so it is declared breaking for the worker wires and its redeploy restarts every part together once (`temper/docs/design/protocol/wires.md`, 3.2), where 3 has the workers stay. No bridge carries an opening from ranges to texts. Decided by the milestone, 2026-11-24.
