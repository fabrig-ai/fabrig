- **No priority mark:** neither milestone is one of v0.1.0's critical pieces. They run when places are free and marked work isn't about to arrive.
- **T1, then T2.** T1 gives the check at apply the typed costs it counts; T2 changes the declarations those costs measure, and adds the brief's floor, which no stock designer can pass before T2's smaller declarations (`tools-by-role.md`, 6). T1 changes the engine's fitting and the settings check (`assignment.rs`, `workers.rs`, the hub link's `payload.rs`, the domain's room and the service's startup); T2 changes `temper-engine-smith`'s declarations, its contract, the `host-tools` page and the stock charters.
- **Before T2's redeploy,** a deployment's charter keepers add the families T2's inventory names, by settings changes.
- **T3 waits for T2's redeploy,** which needs the user's confirmation, as every redeploy does.
