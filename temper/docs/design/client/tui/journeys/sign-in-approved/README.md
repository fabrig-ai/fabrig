# sign-in-approved

On a fresh `temper box --fake-backends`: the browser signed in by the
box's printed link, `temper` started at the box's address, the approval's
frame marked, the approval given in the browser, then the launchpad with
no project yet.

- `01.html` and `01.txt`: the approval's frame, "A tab opened in your
  browser", its code and its address, marked by Alt+Shift+M. The code
  beside "then press Approve." also appears in
  `http://127.0.0.1:PORT/terminal?code=CODE`.
- `02.html` and `02.txt`: the launchpad of a box with no project, "No
  project yet" and how to make the first project, at the recording's end.

The code, the port and the clocks are the recording's own. The walk is
recorded by `again sign-in-approved` from its `walk`; Alt+Shift+S saves
its end. The first replay proves both frames against the live prints.
