playground's composition, with both shipped clients and no box or
terminal (`../../../journey-walks.md`, 4 and 6). Hello has the world's
owned Forgejo repository `work/hello` and an OpenAI sign-in account,
shown as "your ChatGPT plan" with the `fake` model. The browser approves
the TUI's sign-in.

`scripts.json` supplies the chat's delegation and reply, and the goal's
question, wait and finish after the answer. The chat is T2 in project 1;
the delegated goal is T3. It asks the requesting chat, target 2,
"csv-export: comma or semicolon?", with Comma recommended and Semicolon.
`/new` returns to the launchpad; `n` walks the question, and Enter takes
Comma. The scripted model changes no repository.
