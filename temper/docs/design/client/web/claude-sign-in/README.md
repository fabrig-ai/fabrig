# Claude Code's sign-in through the terminal: the browser

Hand-made pages for `../../../draft/claude-sign-in.md`, section 2, and
`index.html`, both sides in order with the terminal's frames in
`../../tui/claude-sign-in/`.

- **From:** the client gallery's `welcome-model-forge-done`
  (`../gallery.md`), printed at main `a9e804e340`, with the cards, the
  note and the pane's Model line changed by hand. Its values are the
  gallery's.
- **Styles:** the client's own, linked from the repository as the
  journeys' prints link them (`../journeys.md`), so the pages follow
  the stylesheets as they change.
- **Pages:** `01-model.html`, the cards with a terminal to lend;
  `02-signing-in.html`, pressed; `03-anthropic.html`, Anthropic's page,
  a placeholder; `04-signed-in.html`, the plan ticked;
  `05-no-terminal.html`, the cards with none.
- **Not the draft's:** the top bar, with no person, no Sign out and no
  temper box line, is the shared welcome frame (`welcome-top`); the box
  paragraph belongs to the Welcome step's main alone. "Open Forgejo ↗"
  under the Forge line, set by a style in each page's head, is the
  separate `forgejo-link` request.
