# github-new-tab

Hand-made from a browser recording of 2026-11-19 on a box built at `7b67d61895`: the welcome's Forge step (`forge-`), and after "Connect GitHub" is pressed, the waiting note in the choices' place (`waiting-`). The note is drawn as ChatGPT's sign-in draws its own, with GitHub's words; its "Open it again" address is an example. The night pages set `data-night` by hand. `*-before.html` is main as drawn, `*-after.html` the request: no rules of its own.
