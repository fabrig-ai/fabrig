# chat-draft

A version-2 `walk`, `after project-landing`, in one process on the
playground's composition (`../../../journey-walks.md`, 4 and 6). Hello
has the world's owned Forgejo repository `work/hello` and an OpenAI
sign-in account, shown as "your ChatGPT plan" with the `fake` model.
The walk reloads the project's settings and sees "Chats can write
drafts", left on as a fresh project has it. From Chats it opens
"+ New chat" and waits for the repository's context line before sending
"Let us design Away mode."

Its `scripts.json` supplies the chat's first reply, the write-up, the
follow-up and the goal's report. In this world the chat is T2 in project
1. The write-up creates note 3; the follow-up inserts seven lines at
line 13 of revision 1, making revision 2 without repeating the document.
Starting the goal makes T3. The report demonstrates the flow; the
scripted model changes no repository.
