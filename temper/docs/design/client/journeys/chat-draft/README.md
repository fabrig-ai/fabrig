# chat-draft

This recording holds the walk through "+ Draft"; the document writes
and goal steps are blocked and are not recorded.

On a fresh `temper box --fake-backends`, built with
`temper/scripts/bundle.sh --loopback --record`: set up Forgejo on this
machine with the offered empty `work/hello`, sign in to the fake ChatGPT
plan, and create Hello. No chat is started during setup.

Reload `/projects/1/settings` to start the recording at How work runs.
Mark the page with Alt+Shift+M, turn on "Chats can write drafts", and
mark it again. Open "+ New chat", send "Let us design Away mode." to
start the first chat, T1, and mark its settled reply. Press "+ Draft",
mark the settled empty pane, and save with Alt+Shift+S.

The fake ChatGPT model replies "Hello from the local fake model." to
both the opening message and "+ Draft"'s "Write this up as a draft
beside us." No note is written: the pane stays at `untitled.md`,
"writing", and "The draft appears here as you write it together."
The demo model has the document cues, but the fake ChatGPT backend
used by this setup does not. Its model picker lists "Scripted model"
as needing an account. Two document turns, the populated Chat, Split
and Draft modes, the Start goal sheet and the goal page remain
unrecorded.
