# welcome-set-up

On a fresh `temper box --fake-backends` (client/journeys.md, 3.5): the
box's printed sign-in link opened, the welcome drawn, "Set up temper"
pressed, then Forgejo on this machine's card chosen on the Forge step,
and its Details' "Set up a Forgejo here" pressed. This makes the forge
and sets Forgejo on this machine up with `work/hello` into a new project
`Default`, the set up running on while the welcome moves to Model.

- `01.html`: the welcome as it was when "Set up temper" was pressed.
  Its "Set up temper" leads to `02.html`.
- `02.html`: the Forge step's choices as they were when Forgejo on this
  machine's card was chosen. The card leads to `03.html`.
- `03.html`: its Details, the set up's fields filled, as they were when
  "Set up a Forgejo here" was pressed. That button leads to `04.html`.
- `04.html`: the Model step, the set up running on, as it was when the
  recording ended.
