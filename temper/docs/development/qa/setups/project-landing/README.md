Hello has the empty work/hello repository on the box's fake Forgejo elsewhere, connected as its admin, and a fake model key added through ctl, with Home's status ready. This state serves the project's Home, Work, Needs you, Ask temper and How work runs pages, the web journeys starting after project-landing, and the TUI journeys' starting screens; the recipe waits for Hello's Home to name work/hello, then checks that Hello's Home says "Hello is ready.", since the root opens Home, never Needs you.

The recipe connects the model with `ctl account add-key 1 {model.key}` and waits with `ctl account list --until usable`, as ctl-hello does. It uses a fake model key rather than a signed-in ChatGPT plan because the plan's sign-in opens a new tab the drive cannot follow.
