reviews) and the brief of the run being replayed. In this run the brief's
How, Machines, Measure and Report are fab's own: implementers are fab runs in
builder slots, every finished branch is merged into `component-kit-4/integration`,
dependents start from its tip, and the queue's full checks run once on it at
the end. Read the brief for the change, what done means, and its decision
rules (section 6: the recommended option, measured where cheap; keep the
critical path short).
