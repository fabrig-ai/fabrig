# codec: status

2026-11-18. Where skein's code lags or departs from [README.md](README.md).

- **Not yet:** 1, 4 and 6: only the families their owner lists in a `lean` file in its `schema/` directory, one family name a line (jig's tasks store), and skein's `every-v3`, written both ways as its pin, are generated as lean records. Every other family keeps the sealed form: private fields behind a `Parts` twin, constructors that check, accessors and `into_parts`, a `Path` enum per family, bounds as generated arithmetic, and functions split by field. `skein_codegen::generate` writes the sealed form, `generate_as` either, and the command the form its first schema's mark gives.
- **Departs:** 6: an option whose value is an option generates `Option<Option<T>>`, which `clippy::option_option` rejects, so generated code does not pass the lints there. Only the pin, `every-v3`, nests options; its module declarations, sealed and lean, in `skein/tests/codec`'s library carry a scoped `#[expect(clippy::option_option, ...)]`, and the generated text carries none. A family that nests options in earnest takes the generator's fix first. Decided by the goal's coordinator, 2026-11-18, to keep the pin off a generator change.
