# temper-05.s2 A call read by `--call` names no FILE

Added by ruling 123, from the designer's answer to 05.6's question, for
session 05 (`05-ctl.md`): it runs after 05.6.

Scope: tools.md, 8.1: "A call `--call` reads gives no argument of the
type a file (5.1), a path or `-`: one that does is a usage error, exit
1, once the call is decoded and before DIRECTORY opens."
Needs: 05.6.
Files: `crates/temper-client-shell-cli/src/host/input.rs`, `src/tests.rs`.
Shape: in `input.rs`'s `prepare_progress`, once `jig::json::call`
returns `Ok(call)`, a call that holds an argument of the file type (its
`Value::File`, or `Value::Stdin` in a file slot) fails as the `Err` arm
does, `self.fail(b"usage: temper ctl DIRECTORY TOOL [ARGUMENT...]")`,
before `self.directory.start`. No new `Startup` field, no decoding
before the loop, and no new root; ruling 111's `Startup.file_parent`
stands.
Test shape: `src/tests.rs`, each under 20 ms, one act each (README,
Rules, ruling 117): `a_call_read_from_a_file_that_names_a_file_is_usage`
(`sign-in FILE` by `--call FILE`) and
`a_call_read_from_stdin_that_names_a_file_is_usage` (by `--call -`):
exit 1, and no DIRECTORY made.
Proof: unit, `cargo nextest run -p temper-client-shell-cli -E
'test(/that_names_a_file_is_usage$/)'`.
Don't: decode `--call`'s call before the loop; open a further root.
Size: about 10 production lines.
Removes: nothing.
