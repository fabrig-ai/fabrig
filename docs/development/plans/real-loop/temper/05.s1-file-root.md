# temper-05.s1 FILE read as given

Added by ruling 111, for session 05 (`05-ctl.md`): it runs after 05.4,
and 08.3 and 05.6 wait for it.

Scope: a FILE that a call names is read as given, absolute or relative
to the working directory (tools.md, 8.1: "read from FILE"), not beneath
DIRECTORY's parent: the kernel resolves every path beneath its root and
refuses an absolute one with `Escape` (skein-io `kernel.rs`).
Needs: 05.3; the same session, after 05.4.
Files: `crates/temper-client-shell-cli/src/{arguments,host,directory,tests}.rs`,
`src/tests/fixtures.rs`.
Shape:
- `arguments::file_root(parsed: &Parsed) -> Option<Box<[u8]>>`: the
  directory of the FILE the call reads, its bytes before the last `/`
  (`/` when that is its first byte, `.` with no `/`); `None` for `-`,
  help, and a call that names no FILE. 05.6 adds `--call FILE` to it.
- `Startup.file_parent: Option<Fd>`: that directory, opened by the entry
  point (05.6's `ctl::run`, by `skein_shell::open_root`; a world's
  startup root, 08.3). The host adopts it into the directory's `FileIo`
  as a second root, owns it and closes it, as `parent`; the slot count
  and host.rs's `FileIo::worst_case` take it.
- `Directory::load_link` loads FILE's leaf, the bytes after its last
  `/`, beneath that root, `no_follow` as now. A FILE named with no
  `file_parent` exits 1 as an unreadable FILE does.
Test shape: `src/tests.rs`, each under 20 ms:
`sign_in_reads_its_file_beneath_the_file_root` (the link's `Load` names
the second root and the leaf `link` for FILE `/elsewhere/link`) and
`file_root_splits_a_file_argument` (`/link`, `a/b/link`, `link`, `-`).
Proof: unit, `cargo nextest run -p temper-client-shell-cli -E
'test(sign_in_reads_its_file_beneath_the_file_root)'`; an absolute FILE
on the real kernel is 08.3's sign-in story.
Size: at most ~60 production lines.
Don't: load FILE beneath DIRECTORY's parent; pass the host an absolute
path to open; read FILE in the entry point or the world.
Removes: nothing.
