skein holds three SHA-256 copies (skein-io's `digest`, PKCE, the bundler) and one
constant-time comparison (skein-oauth's), and lib none (`findings/skein-sha256.md`,

`equal`; temper 05.1 takes skein's `main` once it has landed. 01.3 moves PKCE and the
bundler onto lib's, removing their copies, after 01.2. No public item goes
(decisions.md 3).

## What the design asks

  lib's, `Hmac` (two states seeded with the key's pads) and `equal`.

## Choices this plan makes

- **One module, no root re-export:** `skein_lib::sha256::{Sha256, digest, Hmac,
  equal}`, as `base64` (`lib.rs:18`); the carry is `hashed % 64`; `new` is `const`.
- **`compress` and the constants move from skein-io** (`digest.rs:20-88`, `:159-204`)
  as they are; its three `#![expect]`s (`:6-14`) become scoped `#[expect]`s on
  `compress` alone. `update` and `finish` are new and index nothing
  (`as_chunks::<64>()`, `get_mut`, `zip`; `clippy.toml` bans `copy_from_slice`).
- **`Debug` prints `Sha256 { hashed: N }`,** as `Secret { len: N }` (`secret.rs:30-34`),
  with `crypto_rng.rs:90`'s scoped `#[expect]`. `update` asserts `hashed <= u64::MAX
  / 8`, else "SHA-256 hashes at most 2^64 - 1 bits"; a `#[cfg(test)]`
  `having_hashed` starts a hasher at a count.
- **The step tests hold literals, the fuzzy tests cuts.** `digest` is `new`, one
  `update`, `finish`, so a step test "against the one-shot form" compares the code
  with itself: the step tests compare with digests `sha256sum` and `openssl` print,
  whole and cut at a few points; the fuzzy tests (`tests/lib/tests/fuzzy_bytes.rs`)
  compare every cut with the whole. They compress about 16,000 blocks (the million
  `a`s), 56,000 (the sweep), 90,000 (the random rounds) and 1,500 (HMAC's): at 10 to
  50 microseconds each in lib's unoptimized build (not measured), at most 5 s a test.
- **`Hmac` is two `Sha256`,** each given its pad block in `new` (the key's block XOR
  0x36 for `inner`, 0x5c for `outer`); neither key nor pads are kept. `Debug` prints
  `Hmac { hashed: N }`, N the bytes given to `update`. **`equal`** ORs the XORs of
  the pairs and passes the result through `core::hint::black_box` before comparing
  it with 0 and the lengths.
- **skein-io's words come from a `pub(crate)` `Digest::from_bytes`.** The bundler
  streams its encoding into one `Sha256` (each path, a 0 byte, the length's 8
  little-endian bytes, the bytes). No profile change: `Cargo.toml:130`'s `opt-level =
  3` for skein-ui-bundle does not reach skein-lib.

```rust
/// HMAC-SHA256 (RFC 2104) over pieces cut anywhere (lib.md, 6.2).
#[derive(Clone)]
pub struct Hmac {
    /// Seeded with the key's block XOR 0x36; takes the message.
    inner: Sha256,
    /// Seeded with the key's block XOR 0x5c; takes `inner`'s digest.
    outer: Sha256,
}

impl Hmac {
    /// A MAC keyed by `key`; a key longer than 64 bytes is hashed first.
    #[must_use]
    pub fn new(key: &[u8]) -> Hmac { todo!() }
    /// Authenticates the next piece.
    pub fn update(&mut self, piece: &[u8]) { todo!() }
    /// Ends the MAC: its 32 bytes.
    #[must_use]
    pub fn finish(self) -> [u8; 32] { todo!() }
}

#[expect(clippy::missing_fields_in_debug, reason = "lib.md, 6.2: the count of bytes hashed, never the key or its pads")]
impl core::fmt::Debug for Hmac {
    /// `Hmac { hashed: N }`, N the bytes given to `update`, the pad's 64 not counted.
    fn fmt(&self, f: &mut core::fmt::Formatter<'_>) -> core::fmt::Result { f.debug_struct("Hmac").field("hashed", &self.inner.hashed.saturating_sub(64)).finish() }
}

/// Whether `a` and `b` hold the same bytes, in a time that depends on their lengths alone.
#[must_use]
pub fn equal(a: &[u8], b: &[u8]) -> bool {
    let mut difference = 0_u8;
    for (left, right) in a.iter().zip(b) {
        difference |= left ^ right;
    }
    a.len() == b.len() && core::hint::black_box(difference) == 0
}
```
