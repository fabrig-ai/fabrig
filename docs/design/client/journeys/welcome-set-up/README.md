# welcome-set-up

On a fresh `temper box --fake-backends` (client/journeys.md, 3.5): the
box's printed sign-in link opened, the welcome drawn, "Set up temper"
pressed, then "Run on this machine" on the Forgejo card. This sets
Forgejo on this machine up at once with `work/hello` into a new project
`Default`, the set up running on while the welcome moves to Model.

- `01.html`: the welcome as it was when "Set up temper" was pressed.
  Its "Set up temper" leads to `02.html`.
- `02.html`: the Forge step's choices as they were when "Run on this
  machine" was pressed on the Forgejo card. Its "Run on this machine"
  leads to `03.html`.
- `03.html`: the Model step as it was when the recording ended.
